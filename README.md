## Full-stack app builders

Describe an app, get code with a UI, data and logic you can keep iterating on by chat.

- [Lovable](https://lovable.dev) — Chat-to-app builder producing React/Vite projects, with GitHub sync and Supabase integration.
- [Bolt.new](https://bolt.new) — StackBlitz's in-browser builder that runs full-stack JavaScript apps in WebContainers.
- [v0](https://v0.app) — Vercel's generative UI and app builder, focused on React/Next.js and one-click Vercel deploys.
- [Replit Agent](https://replit.com) — AI agent inside Replit's cloud IDE that builds, runs and deploys apps.
- [Base44](https://base44.com) — All-in-one builder with built-in database, auth and hosting.
- [Veloxa Build](https://veloxahost.com/veloxa-build?utm_source=github&utm_medium=referral&utm_campaign=awesome-ai-app-builders) — AI website and app builder with hosting included on every plan, per-message cost shown in dollars, no seat fees, and code download as plain HTML/CSS/JS.

## Website builders with AI

Traditional site builders that added AI generation — best for marketing sites rather than apps.

- [Framer](https://www.framer.com) — Design-first site builder with AI page generation.
- [Wix](https://www.wix.com) — Drag-and-drop builder with an AI site creator.
- [Squarespace](https://www.squarespace.com) — Template-based builder with AI-assisted site setup.
- [Hostinger Horizons](https://www.hostinger.com/horizons) — Hostinger's prompt-to-web-app builder bundled with hosting.
- [Durable](https://durable.co) — AI website builder for small businesses with built-in CRM tools.
- [10Web](https://10web.io) — AI builder that generates WordPress sites.
- [Mixo](https://www.mixo.io) — Quick AI landing pages for validating ideas.
- [Carrd](https://carrd.co) — Simple one-page sites (not AI-first, but a common alternative for tiny sites).

## Open-source and self-hostable

- [bolt.diy](https://github.com/stackblitz-labs/bolt.diy) — Open-source version of Bolt that lets you pick any LLM provider.

## How to choose

| If you need… | Look at |
|---|---|
| A marketing site fast, minimal tech | Website builders with AI |
| A real app with data and logins | Full-stack app builders |
| To own and move the code | Builders with GitHub sync or code download, or open-source tools |
| Predictable costs | Check how AI usage is metered (credits vs dollars) and whether hosting is extra |
| Full control / privacy | Open-source and self-hostable |
